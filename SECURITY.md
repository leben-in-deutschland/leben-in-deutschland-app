# Security

## Reporting a problem

Please do not open a public issue for a security problem. Report it privately through GitHub: on this repository, **Security → Report a vulnerability** ([direct link](https://github.com/leben-in-deutschland/leben-in-deutschland-app/security/advisories/new)). Only the people who maintain this repository see the report.

Say what you found, how to reproduce it and what is affected: the website, the Android app, the iPhone/iPad app, a workflow, or something in this repository that should not be public. If a secret is involved – a key, a token, a signing file – say where you saw it, but leave its value out of the report.

This is a small project with one owner. Reports are read by a person and answered as soon as that person has read them; a fix goes out with a regular release of the website or the apps. There is no bug bounty.

## What is covered

- The website [lebenindeutschland.org](https://www.lebenindeutschland.org) and the Android and iOS apps built from this repository.
- The repository itself: workflows, release signing, release assets, the Git history.

The app has no account and no server of its own. Learning data stays on the device, and the apps download only public static files. Problems in bamf.de, Google Play, the App Store, GitHub or Vercel belong to their operators.

## Supported versions

The website as it is deployed, and the latest release of each app. Older app versions are not patched – please update.
